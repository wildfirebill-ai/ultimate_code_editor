Features

Monaco Editor

Full VS Code editing experience with syntax highlighting for 100+ languages, multi-cursor, find-and-replace, and split editing.

AI Agent

Autonomous coding agent with multi-provider support (OpenAI, Anthropic, Ollama, Groq, and 15+ more) that can chat, read/write files, run commands, and execute code.

Extension Marketplace

Browse 1800+ real VS Code extensions across 27 categories with detail popups and install/uninstall support.

Integrated Terminal

Full xterm.js terminal with PowerShell support, integrated directly into the editor layout.

Git & GitHub

Full Git integration with status, diff, staging, commit, push/pull. GitHub integration with token auth, repo browser, org accordion, direct clone, create repo, and create PR.

File Explorer

Tree-based file navigation with create, rename, delete, and context menu. Auto-refreshes on workspace changes.

Command Palette

Quick access to all editor actions via Ctrl+Shift+P. Open files, toggle panels, run commands — all from one palette.

Split Layout

Resizable sidebar, editor, terminal, and agent panels. Fully customizable workspace arrangement.
